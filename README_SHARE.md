# カジミル / KAJIMIRU ローカルデモ

日本語カジノ比較サイトを想定した、学習用のフロントエンドUIです。
実在サービスへのリンク、実際の登録機能、決済機能は含まれていません。
掲載されている数値・ボーナス内容はデモ用です。

## 起動方法（日本語）

必要環境：Node.js 22.13 以上

1. このZIPファイルを解凍します。
2. ターミナルで解凍したフォルダを開きます。
3. 次のコマンドを順番に実行します。

```bash
corepack enable
pnpm install
pnpm dev
```

4. ブラウザで `http://localhost:3000/` を開きます。

終了するときは、ターミナルで `Control + C` を押してください。

## 中文说明

这是一个用于学习和内部演示的日语赌场比较网站前端，不包含真实跳转、注册或支付功能，页面中的排名、奖金和评分均为演示数据。

运行环境：Node.js 22.13 或更高版本。

解压后在终端进入项目目录，然后依次运行：

```bash
corepack enable
pnpm install
pnpm dev
```

最后打开 `http://localhost:3000/`。停止运行时，在终端按 `Control + C`。
